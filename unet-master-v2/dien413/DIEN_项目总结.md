# DIEN 项目完整总结

## 🎯 项目概述

**Deep Interest Evolution Network (DIEN)** 是一个用于点击率预测的深度学习模型，采用了注意力机制和循环神经网络来捕捉用户兴趣的演化过程。

## ✅ 已完成的工作

### 1. TensorFlow 2.x 迁移
- **核心文件修复**：
  - `rnn.py`：修复了 RNN 细胞和控制流操作
  - `model.py`：更新了模型架构和层调用方式
  - `utils.py`：实现了自定义 `_Linear` 类
  - `train.py`：更新了训练流程和配置
  - `Dice.py`：修复了激活函数的实现

- **兼容性层**：
  - 创建了 `tf1_compat.py` 提供 TF 1.x 到 TF 2.x 的兼容包装
  - 处理了批量归一化和密集层的调用

### 2. 内存优化
- **批处理大小**：从 128 减小到 32
- **序列长度**：从 100 减小到 50
- **模型规模**：
  - 隐藏层大小：从 36 减小到 12
  - 注意力大小：从 36 减小到 12
  - 隐向量维度：从 128 减小到 64

### 3. 训练验证
- **训练成功运行**：100+ 次迭代
- **性能指标**：
  - AUC：从 0.4891 提升到 0.5290
  - 训练损失：从 1.2465 下降到 0.3466
  - 准确率：从 0.4955 提升到 0.5263
  - 辅助损失：从 0.8988 下降到 0.0042

### 4. 问题解决
- **内存问题**：通过参数调整解决
- **TensorFlow 2.x 兼容性**：通过代码修改和兼容层解决

## 🚀 使用方法

### 1. 训练模型
```bash
cd dien413/dien/script
python train.py train DIEN
```

### 2. 测试模型
```bash
python train.py test DIEN
```

### 3. 配置参数
- `batch_size`：批处理大小（默认 32）
- `maxlen`：最大序列长度（默认 50）
- `HIDDEN_SIZE`：隐藏层大小（默认 12）
- `ATTENTION_SIZE`：注意力大小（默认 12）
- `LATENT_DIM`：隐向量维度（默认 64）

## 🔧 技术细节

### 核心模型架构
1. **嵌入层**：将用户 ID、商品 ID、类别等转换为向量
2. **兴趣提取层**：使用 GRU 捕捉用户兴趣序列
3. **兴趣演化层**：使用注意力机制和 AUGRU 捕捉兴趣演化
4. **全连接网络**：将特征组合并输出预测结果
5. **辅助损失**：使用辅助网络增强模型性能

### 关键技术
- **注意力机制**：捕捉用户兴趣的动态变化
- **AUGRU**：带注意力的门控循环单元
- **Dice 激活函数**：自适应激活函数
- **辅助损失**：增强模型的序列建模能力
